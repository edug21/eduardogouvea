# Eduardo Gouvêa — Portfolio

Personal portfolio site (English / Português). Static HTML, no build step.

## Publish with GitHub Pages

1. Create a repository on GitHub (for a root site, name it `<your-username>.github.io`).
2. Upload every file in this folder to the repository root (including `.nojekyll`).
3. In the repository, go to **Settings → Pages**, set **Source** to *Deploy from a branch*, branch `main`, folder `/ (root)`, and save.
4. After a minute or two the site is live at `https://<your-username>.github.io/` (or `/<repo-name>/` for other repository names).

`?lang=pt` opens the Portuguese version directly.
